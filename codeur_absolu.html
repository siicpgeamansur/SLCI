Codeur absolu

Un disque porte n pistes codées, lues chacune par une photodiode. Le mot de n bits obtenu donne directement la position angulaire θ du disque, sans remise à zéro ni comptage.

Disque et capteurs

Une piste par bit : la plus proche du centre porte le bit de poids fort (MSB), la plus externe le bit de poids faible (LSB). Zone transparente = bit 1 (5 V), zone opaque = bit 0 (0 V). Le trait clair du moyeu marque θ = 0.

Chronogramme des capteurs

Une ligne par piste : tension de la photodiode (0 V ou 5 V), bit de poids fort en haut. La ligne N est la valeur décodée, en rouge quand elle diffère de la position réelle.

Position angulaire absolue θ

Contrairement au codeur incrémental, le codeur absolu donne θ elle-même et pas une variation Δθ. Elle revient à 0 à chaque tour. Coupez l'alimentation puis rallumez : la bonne position est lue aussitôt.

Formules

Avec n le nombre de pistes, N la position décodée (entier de 0 à 2ⁿ − 1). Les lignes en dessous reprennent vos réglages.

Nombre de positions

M = 2n

Chaque piste ajoute un bit, donc double le nombre de secteurs distincts.

Résolution angulaire

Δθmin = 360°2n

C'est la largeur d'un secteur : toutes les positions à l'intérieur donnent le même mot.

Angle absolu

θ = N × 360°2n

θ est mesuré depuis la référence du disque (trait clair du moyeu).

Binaire vers Gray

g = b ⊕ (b ≫ 1)

⊕ est le OU exclusif, ≫ 1 décale le mot d'un rang vers la droite.

Gray vers binaire

bn−1 = gn−1  ;  bi = bi+1 ⊕ gi

Le décodage se fait bit par bit, du poids fort vers le poids faible.

Pourquoi le code Gray

Gray : 1 bit change  /  binaire : jusqu'à n

Si les capteurs ne commutent pas exactement ensemble, un mot binaire intermédiaire peut être très faux. En Gray l'erreur reste d'un secteur au plus.
